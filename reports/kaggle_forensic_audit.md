## 1. Executive Summary

This forensic audit investigates whether the completed Kaggle GPU execution (`foxy0505/finevent-nlp-training-gpu`) trained and evaluated on authentic, verified SEC disclosures or reused the legacy 290-record synthetic-contaminated dataset.

### Definitive Conclusion:
The completed Kaggle run **DID NOT** train or evaluate on the 20-record authentic SEC dataset. Due to the fallback logic in `kaggle/train_finevent.py`, the remote worker dynamically retrieved files from GitHub raw `main` at commit `662aabe`, which contained the **legacy 290-record dataset (260 template-generated synthetic samples, 30 seeds)**. 

Consequently, all previously claimed E2 results (DeBERTa Macro-F1 = 0.3677 and FinBERT Macro-F1 = 1.0000) reflect performance on **HISTORICAL_SYNTHETIC** data, and **cannot be directly compared** to the 5-sample local baseline E0/E1.

## 2. Answers to the 10 Mandatory Audit Questions

### Q1: Did the kernel actually complete?
- **Status**: `VERIFIED`
- **Evidence**: Kaggle CLI status returned `KernelWorkerStatus.COMPLETE`. Remote execution finished with exit code 0. Execution log and summary JSON `final_cloud_benchmark_summary.json` were produced and downloaded.

### Q2: Which GPU was used?
- **Status**: `VERIFIED`
- **Evidence**: Kaggle execution logs confirm `Compute Device: cuda` running on NVIDIA Tesla T4 with PyTorch single-device isolation (`CUDA_VISIBLE_DEVICES = "0"`).

### Q3: Which dataset did it load?
- **Status**: `VERIFIED`
- **Evidence**: Execution log lines 9-23 confirm:
  ```text
  Downloading train.jsonl from GitHub raw...
  Downloading val.jsonl from GitHub raw...
  Downloading test.jsonl from GitHub raw...
  Splits loaded: Train=183, Val=51, Test=56
  ```
  The script loaded `train.jsonl` (183 samples), `val.jsonl` (51 samples), `test.jsonl` (56 samples).

### Q4: Was the dataset real, synthetic, or mixed?
- **Status**: `HISTORICAL_SYNTHETIC` (Mixed, heavily synthetic)
- **Evidence**: The 290-record corpus at commit `662aabe` contained 260 programmatic text-template records generated by `expand_curated_dataset()` in `src/ingest/build_dataset.py`, with repeated syntactic boilerplate and synthetic entities.

### Q5: Which checkpoint was selected?
- **Status**: `VERIFIED`
- **Evidence**: 
  - For DeBERTa-v3: `checkpoint-12` (Epoch 1) was selected as `best_model_checkpoint` based on validation Macro-F1 = 0.3588 (before overfitting occurred at Epoch 2 and 3).
  - For FinBERT: `checkpoint-12` (Epoch 1) was selected based on validation Macro-F1 = 1.0000.

### Q6: Can the reported metrics be recomputed?
- **Status**: `UNVERIFIED` (Historical prediction-level files absent)
- **Evidence**: The remote training script output aggregated `metrics.json` and confusion matrices, but did not persist an immutable `test_predictions.jsonl` file per sample on Cloud storage. The raw checkpoint weights cannot reproduce metrics without downloading the 500MB+ files (which violates Rule 1 of `AGENTS.md`).

### Q7: Are E0/E1/E2 results directly comparable?
- **Status**: `CONTRADICTED`
- **Evidence**: E0 and E1 were evaluated on the 5-sample local test set from `data/labels/test.jsonl`. E2-A and E2-B were evaluated on the 56-sample legacy test set. Presenting them in a single table as a unified benchmark was methodologically invalid.

### Q8: What is the status of DeBERTa Macro-F1 = 0.3677?
- **Status**: `HISTORICAL_SYNTHETIC`
- **Evidence**: Achieved on the 56-sample legacy test set (Support: GUIDANCE_REVISION=16, EARNINGS_RESULT=15, MANAGEMENT_CHANGE=13, OTHER=12). The model learned EARNINGS_RESULT (F1=0.9286) but failed to generalize on other classes with general-domain representations.

### Q9: What is the status of FinBERT Macro-F1 = 1.0000?
- **Status**: `HISTORICAL_SYNTHETIC` (Synthetic Artifact)
- **Evidence**: The apparent 1.0000 Macro-F1 resulted from domain-pretrained financial embeddings fitting predictable synthetic template phrasings across all 4 classes. It does NOT represent 100% accuracy on unstructured real-world SEC filings.

### Q10: Which historical claims must be retracted or relabeled?
- **Status**: `CONTRADICTED` claims identified:
  1. The claim in `README.md` and `reports/results.md` that E2-A and E2-B were evaluated on the authentic SEC dataset is **RETRACTED**.
  2. The unified comparison table combining 5-sample E0/E1 with 56-sample E2 is **RETRACTED**.
  3. All historical E2 metrics are formally relabeled as `HISTORICAL_SYNTHETIC_SANITY`.
